# UXF-008: The search box's shortcut hint fails contrast in the light theme

- id: UXF-008
- title: The search box's shortcut hint fails contrast in the light theme
- class: affordance
- severity: S2
- metric: axe.serious
- status: closed
- found_by: R-01 follow-up gates (axe-core `color-contrast`), after adding the search plugin (UXF-002)
- evidence_recording: none (no recorded sessions this round)
- evidence_screenshot: none
- evidence_lines: the first gate run with search: every page, 1366x768 light: `axe: color-contrast (1): kbd:nth-child(1)`
- regression_asset: ux/search.spec.ts (and the axe-core gate in ux/gates.spec.ts)
- cost: S

The search plugin draws its keyboard shortcut hint (`kbd`, "ctrl K") in Infima's search placeholder
colour (`--ifm-color-emphasis-500`) on the search box background, below 4.5:1 in the light theme.
Introduced by the UXF-002 fix, so fixed in the same change.

Fix: `website/src/css/custom.css` draws `.navbar kbd` in `--ifm-color-emphasis-700`, which follows
the theme.

Red before, green after: the axe-core gate failed on all 17 pages in the light theme with the plugin
and the old colour, and passes after; `ux/search.spec.ts` holds the hint with its own axe check.
