# UXF-001: The site's colours never applied; Infima's blue fails contrast on every page

- id: UXF-001
- title: The site's colours never applied; Infima's blue fails contrast on every page
- class: affordance
- severity: S2
- metric: axe.serious
- status: closed
- found_by: R-01 gates (axe-core `color-contrast`, skill § 4 gate 5)
- evidence_recording: none (no recorded sessions this round)
- evidence_screenshot: ux/rounds/R-01/shots/before-docs_install@1366x768-light.png, ux/rounds/R-01/shots/after-docs_install@1366x768-light.png
- evidence_lines: ux/rounds/R-01/report-before.md, every page in both themes: `axe: color-contrast`
- regression_asset: ux/brand.spec.ts (and the axe-core gate in ux/gates.spec.ts)
- cost: S

Every page, both themes, failed WCAG AA contrast: the active navbar link, the active sidebar link,
the active breadcrumb, sidebar category labels and links in text were `#3578e5` (Infima's default
blue) at 3.0 to 4.2:1 on their backgrounds; on the landing page the eyebrow line was 3.33:1.

Cause: `src/css/custom.css` (purple `#7251a8` light, `#d3a6ff` dark, a darker dark background)
never applied. `future.v4` puts Infima in CSS cascade layers; with no `browserslist` in
`package.json`, the default list includes browsers without `@layer`, so `postcss-preset-env`
rewrote the layers into selectors with two extra `:not(#\#)`, stronger than the unlayered
`custom.css`. Diagnosis: the built CSS held `:root:not(#\#):not(#\#){--ifm-color-primary:#3578e5}`
before `:root{--ifm-color-primary:#7251a8}`, and computed `--ifm-color-primary` was `#3578e5`.

Fix: `website/package.json` `browserslist` names browsers with native `@layer` support (Chrome and
Edge 99, Firefox 97, Safari 15.4, Samsung 18). The build keeps `@layer` (0 `:not(#\#)` in the CSS),
`custom.css` wins, and `color-contrast` reports 0 nodes on every page in both themes.

Note: a stale build cache keeps the old CSS; the first rebuild after the change needs
`docusaurus clear` (CI builds clean).

Red before, green after: `ux/brand.spec.ts` fails against the R-01 before-build (computed
`--ifm-color-primary` `#3578e5`) and passes against the fixed build.
