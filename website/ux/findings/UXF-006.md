# UXF-006: A table that scrolls sideways cannot be reached by keyboard

- id: UXF-006
- title: A table that scrolls sideways cannot be reached by keyboard
- class: affordance
- severity: S2
- metric: axe.serious
- status: closed
- found_by: R-01 round measurement, measured-only sizes (axe-core `scrollable-region-focusable`)
- evidence_recording: none (no recorded sessions this round)
- evidence_screenshot: none
- evidence_lines: ux/rounds/R-01/report-mid.md: `docs/structure` at 1024x768 and 390x844, both themes: `axe: scrollable-region-focusable (1): table:nth-child(5)`
- regression_asset: ux/narrow.spec.ts
- cost: S

Infima renders a Markdown table as a block that scrolls sideways when it is wider than the column.
On `docs/structure` the R1–R8 table does that below 1280 px, and a keyboard user cannot scroll it:
the table takes no focus. Not seen at the gating sizes, where the table fits.

Fix: `website/src/theme/MDXComponents.tsx` wraps the Markdown `table` with `tabIndex={0}`.

Red before, green after: `ux/narrow.spec.ts` fails against the build before the fix (the table has
no `tabindex`, axe-core reports the rule) and passes after.
